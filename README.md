# ga-forms
An Open Source WordPress Forms Plugin
AI is used to generate the code.
Follow instructions in each document generated.
The process to develop this pugin:
  1. Get a description of a commercial alternative (plugin)
  2. Create PRD for the plugin
  3. Create a master prompt for creating the plugin
  4. Ask AI to interview you or fillout the related document with information from AI.
  5. Leverage AI for Assumptions of AI for this plugin
  6. Review and Approve suggested options base on the competition
